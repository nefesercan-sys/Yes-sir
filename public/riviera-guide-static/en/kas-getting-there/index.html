Getting to Kaş

Kaş is a small, remote-feeling Lycian coast town; the journey is part of the trip.

Updated: 2026-10-24

Tips

  • Dalaman is the closest large airport.
  • Minibuses run frequently to Kalkan; long-distance buses run daily in summer and less often off-season.
  • Roads are winding; allow extra time.
